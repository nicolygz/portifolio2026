PROJETO ACADÊMICO EM PARCERIA COM HELPNEI • SCRUM • 2º SEMESTRE FATEC SJC insights

Helpnei — Dashboard de Indicadores

Projeto desenvolvido no 2º semestre de Desenvolvimento de Software Multiplataforma na Fatec São José dos Campos, em parceria com a Helpnei e utilizando metodologia Scrum. A solução consiste em um dashboard interativo para centralizar indicadores da plataforma, apresentando dados sobre lojas, usuários e transações. O sistema conta com filtros por período e localização, gráficos dinâmicos e visualizações geográficas para facilitar a análise dos dados e apoiar decisões estratégicas.

PROJETO ACADÊMICO • CIVIC TECH account_balance

Transparência dos Vereadores — The Devs Department

Projeto desenvolvido para transformar dados públicos da Prefeitura de São José dos Campos em informações interativas sobre a atuação dos vereadores. A plataforma apresenta dados relacionados a proposições realizadas, assiduidade, participação em comissões e avaliação do mandato pelos cidadãos, buscando incentivar transparência e engajamento cívico.

Estação Meteorológica IoT — Inception

Desenvolvida em parceria com a Tecsus, a estação meteorológica IoT monitora e processa variáveis climáticas em tempo real para agricultura de precisão. Os dados coletados via redes IoT (Sigfox, LoRa, NB-IoT) alimentam um portal web com dashboards e relatórios analíticos de alta disponibilidade.
