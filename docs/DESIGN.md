## Brand & Style

The design system establishes a high-caliber digital identity for an elite software developer. The aesthetic intersects modern editorial precision with advanced architectural computing. It projects confidence, high technical mastery, and refined taste.

The experience is feminine, sharp, and commanding—eschewing pastel tropes or fragile minimalism in favor of deep atmospheric blacks, luminous spectral violets, and structured typographic layouts. The interface evokes the atmosphere of a premier engineering atelier: focused, pristine, and structurally disciplined.

## Colors

The palette is engineered specifically for immersive dark mode environments:

- **Surface Base & Depths:** Canvas starts at `#050507` (void), elevating into `#09090b` for foundational panels and `#121118` for floating cards.
- **Accents & Spectra:** Primary violet `#a855f7` provides energetic punctuation, paired with `#c084fc` for luminous interactive highlights, tooltips, and hyper-focused links.
- **Structural Outlines:** Borders utilize deep plum `#2e1065` and muted amethyst `#3b1d6e` at 40%–70% opacity, providing crisp structure without clinical contrast.
- **Typographic Neutral:** Primary typography uses `#f4f4f5` (96% luminance) for razor-sharp readability, supported by `#a1a1aa` for secondary descriptions and `#71717a` for metadata and technical indicators.

## Typography

Typography balances sculptural expression and pure operational efficiency:

- **Syne (Headlines):** Used across hero statements, section headings, and featured project titles. Its sweeping, distinctive curves inject an editorial, artistic gravitas.
- **Inter (Body):** Used for case study narratives, technical deep dives, and long-form prose, providing neutral, effortless legibility on black surfaces.
- **Space Grotesk (Labels & Monospace Accents):** Deployed for metadata, tags, commit timelines, metrics, and navigation items to evoke technical precision. Always set with generous letter-spacing.

## Layout & Spacing

The layout is grounded in a 12-column architectural fluid grid, capped at a maximum inner container width of 1280px to maintain reading line lengths.

- **Desktop (1024px+):** 12 columns, 1.5rem gutter, 4rem outer margin. Asymmetric split columns (e.g., 5-col narrative, 7-col interactive preview).
- **Tablet (640px - 1023px):** 8 columns, 1.25rem gutter, 2rem outer margin.
- **Mobile (<640px):** 4 columns, 1rem gutter, 1.25rem outer margin. Components stack linearly into cohesive vertical cascades.

Spacing between major thematic sections uses expansive breathing room (5rem to 8rem) to mimic an editorial monograph.

## Elevation & Depth

Visual hierarchy uses tonal surface elevation, low-contrast ghost borders, and controlled violet luminescent backdrops:

- **Layer 0 (Canvas):** Pure deep `#050507`.
- **Layer 1 (Subsurface/Rails):** `#09090b` with a 1px border of `rgba(59, 29, 110, 0.4)`.
- **Layer 2 (Cards & Modules):** `#121118` with a 1px border of `rgba(168, 85, 247, 0.15)`.
- **Layer 3 (Floating Overlays & Modals):** `#181622` backed by a 24px backdrop blur (`backdrop-filter: blur(24px)`), bound by `rgba(192, 132, 252, 0.3)`.
- **Luminescence:** Interactive hover states and key metrics utilize a soft radial glow (`box-shadow: 0 0 35px -8px rgba(168, 85, 247, 0.25)`). Heavy drop shadows are strictly forbidden in favor of ambient chromatic halos.

## Shapes

The interface embraces a tailored "soft-sharp" silhouette:

- Default components (buttons, text inputs, badges) use subtle `0.25rem` (4px) corner radii, preserving a tight, technical look.
- Interactive cards, terminal displays, and project modal containers use `rounded-lg` (`0.5rem` / 8px).
- Status dots and contextual avatars remain strictly circular (`rounded-full`).

## Components

### Buttons
- **Primary:** Background `#a855f7`, text `#050507` (bold `Space Grotesk`), subtle inset light line. On hover, background shifts to `#c084fc` with a `0 0 20px rgba(168, 85, 247, 0.45)` aura.
- **Secondary (Ghost Outline):** Background transparent, 1px border `rgba(168, 85, 247, 0.4)`, text `#f4f4f5`. On hover, background fills with `rgba(168, 85, 247, 0.08)` and border brightens to `#a855f7`.

### Chips & Badges
- Background `rgba(59, 29, 110, 0.35)`, border `1px solid rgba(168, 85, 247, 0.3)`.
- Typography set in `label-sm` (`Space Grotesk`, uppercase), color `#c084fc`. Used for tech stack taxonomy (e.g., `REACT`, `TYPESCRIPT`, `RUST`).

### Cards & Project Showcases
- Surface `#121118` with a 1px border of `rgba(59, 29, 110, 0.5)`.
- Hover triggers a smooth 200ms transition that shifts the border to `rgba(168, 85, 247, 0.5)` and illuminates a top-edge linear gradient hairline in `#a855f7`.

### Form Inputs
- Background `#09090b`, border `1px solid #2e1065`, text `#f4f4f5`, placeholder `#71717a`.
- Focus state brings a sharp 1px border in `#a855f7` paired with a delicate `0 0 0 3px rgba(168, 85, 247, 0.15)` focus ring.

### Terminal & Code Blocks
- Background `#08070d`, header bar with muted violet controls, monospaced data rendered in `Inter` or `Space Grotesk`, keywords highlighted in luminous `#c084fc` and `#f4f4f5`.
